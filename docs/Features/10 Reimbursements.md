# 10 · Reimbursements

Producers' out-of-pocket shoot expenses. Own tab, linked to a closing sheet but approved separately.

## Fields
Producer · shoot/project · date · vendor/expense description · amount · payment mode (UPI | CASH) · receipt upload.

## Flow
Submit → SrProd reviews (§7 #7) → Approve / Reject / Request Changes, **unlimited revisions**, independent of the
sheet's own approval (§7 #8). Approved ones auto-compile into a **separate PDF summary** appended to every dispatch.
Producer notified when accounts marks paid (§7 #9).

## Status
`SUBMITTED → APPROVED | CHANGES_REQUESTED | REJECTED → PAID`
